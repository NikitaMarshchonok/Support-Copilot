# Host Payouts (Demo)

## Summary
- Payouts are released after check‑in or per partner agreement.
- Delays can occur due to verification or banking issues.
- For disputes, collect transaction ID and evidence.

## Rules
1) Verify property and booking ID before sharing payout details.
2) If payout is pending post‑check‑in, provide expected timeline per agreement.
3) If payout failed, request updated bank details and escalate to payments team.

## Required info
- Booking ID
- Property ID
- Expected payout date
- Bank account last 4 digits (if required by policy)

## Suggested wording
"Payouts are typically released after check‑in. I can confirm the exact timeline once I have the booking and property IDs."
