# Cancellations Policy (Demo)

## Summary
- Always verify booking ID, dates, and the guest/host role.
- Check rate type: refundable vs non‑refundable.
- If a medical exception is requested, follow the exception flow and request documentation.

## Rules
1) If the booking is **refundable** and cancellation is within the allowed window, process the refund per policy.
2) If **non‑refundable**, explain the policy and offer alternatives (date change, voucher) if allowed.
3) If the guest reports **medical reasons**, request supporting documents and escalate to L2 if exception applies.

## Required info
- Booking ID
- Check‑in / check‑out dates
- Rate type (refundable / non‑refundable)
- Reason for cancellation

## Suggested wording
"According to our cancellation policy, I need the booking ID and dates to confirm eligibility. If this is a medical exception, please share supporting documents."
# Cancellations (Sample)

If a guest requests cancellation, verify booking ID, dates, and reason.
If the booking is non-refundable, politely explain the policy and offer alternatives if available.
If a refund exception applies, escalate to L2 with full context.
